# 娛樂費轉投資

一個以月為單位管理娛樂費與股票投入的手機版 PWA。

## 功能

- 新增娛樂費與簡單備註
- 新增股票投入
- 自動計算待投資餘額
- 依月份切換查看
- 娛樂費明細與股票投入明細分開顯示
- JSON 備份匯出與匯入
- PWA 離線使用
- 資料儲存在瀏覽器 localStorage

## GitHub Pages

1. 將全部檔案上傳到 Repository 根目錄
2. 進入 Settings → Pages
3. Source 選 Deploy from a branch
4. Branch 選 main，資料夾選 / (root)
5. 儲存後等待 GitHub Pages 網址產生
