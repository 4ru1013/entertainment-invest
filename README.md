# 娛樂費轉投資 V3.4

## V3 更新

- 清新淡紫色 UI
- 日期欄位垂直置中並維持 iPhone Safari 相容
- 新增「轉投資總覽（累積）」：累積娛樂費、累積股票投入、累積完成率
- 移除頁面底部備份區
- 匯出／匯入備份集中於左上角選單
- 保留修改、刪除、清空本月與月份切換
- 保留既有 localStorage 資料相容性


## V3.1 修正

- 月份選擇改為原生月份選擇器，選完即直接套用，不再需要第二次按「套用」
- 明細金額只顯示數字，例如 `300`、`1,500`
- 移除「紀錄股票投入」前面的 `+`


## V3.2 修正

- 修正 V3.1 HTML 與 JavaScript 版本不一致造成的本月總額、累積總額與明細筆數顯示為 0
- 自動讀取並移轉 V2 / V1 已存在的 localStorage 資料
- 明細金額只顯示純數字，不顯示 NT$、+ 或 -
- 月份選完即直接切換
- 更新 Service Worker cache，避免 Safari 繼續混用舊版程式


## V3.3 關鍵修正

1. 修正資料遷移：
   - 如果 V3 localStorage 是空陣列 `[]`，會繼續尋找 V2 / V1 的非空資料。
   - 找到舊資料後會自動搬到 V3，不需要重新輸入。

2. 修正 Safari 舊快取：
   - `app.js` 與 `style.css` 加入 `?v=3.3` 版本參數。
   - service worker 改為 network-first。
   - 啟用新版 service worker 時會刪除舊 cache。

3. 保留 V3.2 功能：
   - 明細金額只顯示數字。
   - 月份選完直接切換。
   - 修改、刪除、備份與累積總覽保留。


## V3.4 修正

- 移除月份標題下方「娛樂支出轉為股票投入」小字
- 月份標題區直接覆蓋原生 iPhone month input
- 點月份一次即可開啟 iOS 月份選擇器
- 移除 `showPicker()` 方式，避免 Safari 點擊無反應
