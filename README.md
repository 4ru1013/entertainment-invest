# 娛樂費轉投資 V2.1

以月為單位管理娛樂費與股票投入的手機版 PWA。

## V2 功能

- 月份切換
- 娛樂費與股票投入分開新增
- 自動計算待投資餘額與完成率
- 娛樂費明細與股票投入明細分頁顯示
- 點擊明細即可修改日期、金額與備註
- 單筆刪除與再次確認
- 清空本月資料與再次確認
- JSON 備份匯出／匯入
- PWA 離線使用
- 資料儲存在瀏覽器 localStorage

- 修正 iPhone Safari 日期與月份欄位超出卡片寬度
- 左上角選單新增實際功能
- 選單可匯出備份、匯入備份、前往備份區與清空本月
